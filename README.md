# FCJ Document Management System (front-end)

React front-end used by the **FCJ Serverless – Document Management System** workshop series (000133 → 000140).

- Vite + React 18
- AWS Amplify JS v6 (Amplify Gen 2)
- Sign-in with **email**; the display name is stored in the Cognito attribute `preferred_username`
- Files are stored in S3 under `protected/{identityId}/{file name}`
- Document information is read and written through API Gateway (`src/constant.js` → `APP_API_URL`)

## Requirements

- Node.js 22.12 or later (`node -v`)
- AWS credentials configured on your machine (for `npx ampx sandbox`)

## Commands

| Command | Description |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Start the app at http://localhost:3000 |
| `npm run build` | Build the app into the `dist/` folder |
| `npx ampx sandbox` | Deploy the Amplify Gen 2 backend and generate `amplify_outputs.json` |
| `npx ampx sandbox delete` | Delete the Amplify sandbox resources |

## Configuration the learner edits

| File | What to change | Workshop |
|---|---|---|
| `amplify/auth/resource.ts` | Define (`defineAuth`) or reference (`referenceAuth`) the Cognito resources | 134, 136 → 140 |
| `amplify/storage/resource.ts`, `amplify/backend.ts` | Define the S3 storage, or add the existing S3 bucket created by AWS SAM | 134, 136 → 140 |
| `src/component/Home/Upload.jsx` | Uncomment the line that writes document information to DynamoDB (`// await api.post("/docs", item.info);`). The line is commented by default because there is no API in workshop 134 | 135 |
| `src/constant.js` | Replace `APP_API_URL` with the Invoke URL of your API Gateway stage | 135 → 140 |

`amplify_outputs.json` is generated by `npx ampx sandbox` and is ignored by Git.
If it does not exist, the app shows a message asking you to run the sandbox.

## How the series uses this repository

| Workshop | Backend | What happens in this repository |
|---|---|---|
| 133 | DynamoDB + Lambda (console) | Not used yet |
| 134 | Amplify Gen 2 creates Cognito + S3 | `npm create amplify@latest`, write `defineAuth` / `defineStorage`, run `npx ampx sandbox`. The DynamoDB line in `Upload.jsx` stays commented because there is no API yet |
| 135 | API Gateway + Lambda from 133 | Uncomment the DynamoDB line in `Upload.jsx`, set `APP_API_URL`, `npm run build`, upload `dist/` to S3 |
| 136 | AWS SAM creates Cognito, S3, DynamoDB, Lambda, API | Replace `defineAuth` with `referenceAuth` and add the SAM bucket with `backend.addOutput`, run `npx ampx sandbox`, set `APP_API_URL` |
| 137 | SAM + CloudFront + ACM + Route 53 | Same as 136 with the new stack values |
| 138 | SAM + OpenSearch (search API) | Same as 136; the search box calls `GET /docs/{id}/search` |
| 139 | CodePipeline / CodeBuild | Build with `npm ci` and `npm run build`, artifact folder `dist/` |
| 140 | SAM + X-Ray / CloudWatch | Same as 136 |

## API used by the front-end

All requests include the Cognito ID token in the `Authorization` header.

| Method | Path | Body / Query |
|---|---|---|
| `POST` | `/docs` | `{ user_id, identityId, file, folder, type, size, tag }` |
| `GET` | `/docs/{id}` | – (returns the list of documents) |
| `DELETE` | `/docs/{id}` | `?file=<file name>` |
| `GET` | `/docs/{id}/search` | `?key=<keyword>&field=file.S\|type.S\|tag.S` (workshop 138 and later) |

Used storage and the amount of files are calculated from `GET /docs/{id}`.
